# PIA-HR-SYSTEM-

PIA AI-Powered Careers & Talent Acquisition Portal.

## Features
- **Job Board & Application Portal**: Interactive job listings and online applications.
- **ATS Resume Scoring**: Resume parsing with OCR and PDF text extraction.
- **Online Assessment Center**: Timed MCQs, categorized tests, and proctoring.
- **AI Video Interview**: Real-time speech synthesis/recognition and multi-face proctoring.
- **HR Dashboard**: Applicant tracking system, stage pipeline, custom questions, and analytics.

## Getting Started
1. Run the application:
   ```bash
   npm start
   ```
   Or double-click `start.bat`.
2. Open your browser and go to:
   ```
   http://localhost:5000/
   ```
